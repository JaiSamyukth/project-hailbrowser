⚡ Add HailBrowser to your browser

A one-time step. After this, the start script keeps it up to date by itself.

  1. Go to the Extensions tab that opened next to this one (or type chrome://extensions in the address bar).
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked and choose this folder (it also opened in a file window):
    the extension folder inside HailBrowser
  4. Click the puzzle-piece icon in the toolbar and pin HailBrowser.
  5. Click the HailBrowser icon (or press Alt+H) to open the side panel, then open Settings and add an API key for the model you want to use.

Keep the HailBrowser folder where it is: the browser loads the extension from it. If you move it, load it again from the new place.

⚡ HailBrowser is ready

Click the HailBrowser icon in the toolbar or press Alt+H to open the side panel.

Run the start script whenever you want: it checks GitHub for updates, and the extension reloads itself into the new version when it is not busy.
